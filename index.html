How to use

Sentences — enter one or more English sentences to translate. Use Add sentence for multiple sentences. Toggle Show answer key to enter the reference translation and intended key (hidden from students).

Worksheet — identify the atomic clauses in each sentence and assign a propositional letter to each. Build your own key row by row. Hit Reset to start over.

Translation — type the symbolic translation of each sentence using your key. Hit Check to see if it is logically equivalent to the reference. Hit Reveal to see the reference answer.
